Lionel Bui - Email Signature

Files:
- lionel-bui-email-signature.html : HTML signature template
- lionel-bui-profile.png          : profile image used by the signature

IMPORTANT:
For Gmail/Outlook and other recipients, host lionel-bui-profile.png on a public HTTPS URL
(e.g. your website/CDN), then replace:
    src="lionel-bui-profile.png"
with:
    src="https://YOUR-DOMAIN.COM/path/lionel-bui-profile.png"

The HTML uses table-based layout and inline CSS for broad email-client compatibility.
